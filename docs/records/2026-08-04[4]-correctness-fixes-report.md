### Принятые решения (не перерешивать без пользователя)

- **H2 — направленный сдвиг к границе суррогатной пары** (решение
  пользователя, обсуждено и зафиксировано): позиция внутри пары в
  `insertBefore` сдвигается к началу пары, в `insertAfter` — к концу.
  Реализация: в `_seamAt` при обнаружении mid-pair внутри куска
  (`offset ≥ 1 && isHigh(u[offset-1]) && isLow(u[offset])`) —
  самоперевызов с `after ? pos+1 : pos-1` (глубина рекурсии ровно 1).
  Пары, разорванные escape-кодом между кусками, — одинокие суррогаты
  самого входа, не трогаем. Плюс: документация code-unit-семантики
  (`length`/`pad*`/`substring` — как у `String`), переформулировка
  README «counts what is seen», оговорка «валидный UTF-16, не графемы»,
  CHANGELOG Fixed.
- **H1**: восстановление зеркально отключению — сначала `lineMode`,
  потом `echoMode`, вложенный try/finally (`current_cursor_pos.dart:43-47`).
  Red-green: новый тест-файл с Windows-фейком stdin, бросающим при
  `echoMode = true` пока `lineMode == false` (и `lineMode = false` при
  включённом эхе) — ограничения из доки SDK. Существующий тест-файл не
  редактировать (фейк дублируется — паттерн проекта).
- **M1**: `substring` отслеживает ссылку, ЭМИТИРОВАННУЮ в буфер (не
  состояние входа): `Link` с непустым url в выводе — открыта, с пустым —
  закрыта; при `close: true` и открытой — `linkClose` перед финальным
  `transitTo` (зеркально `_insert`). Срез, начавшийся внутри ссылки,
  открытия не эмитит — закрытие не дописывается. `close: false` —
  оставить и задокументировать.
- **M8**: два механизма по форме поверхности. Mirrors-свип (VM):
  `Styles` (783 static const — имя строится из `Colors.values`, ищется
  через ClassMirror, значение сверяется с формулой), статики `Color256`,
  top-level `fg256*/bg256*/underline256*` против функций `fg256(i)`.
  Source-проверка для extension `StyleColors` (mirrors расширения не
  видят): regex по `style_colors.dart`, правило «имя ↔ слот+цвет тела»,
  полнота, дубли. Точную грамматику имён Styles закрепить в плане по
  фактическому styles.dart.
