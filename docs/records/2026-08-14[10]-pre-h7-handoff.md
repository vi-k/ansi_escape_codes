## Принятое решение H7

Спека — `docs/records/2026-08-14[7]-stack-reset-semantics-design.md`, коммит
`ad53b97`.

- Один ANSI selective reset не несёт границ вложенной области: для терминала
  `SGR 39` означает foreground по умолчанию, а не предыдущий foreground.
- `Style`, `Parser`, `Printer` и `SinkPrinter` остаются терминальной моделью.
  `Style.call` должен создавать `Printer(defaultStyle: this)` вместо
  `StackedPrinter`, не меняя остальной общий printer pipeline.
- Вложенная конструкция
  `Styles.red('abc${Styles.green('green')}def')` обязана остаться
  red/green/red и байт-в-байт дать
  `[reset][fg256Red]abc[fg256Green]green[fg256Red]def[reset]`.
- `Stack`, `StackedParser`, `StackedPrinter`, `StackedSinkPrinter` и
  `runZonedStackedPrinter` сохраняются публичными. Их selective reset по-прежнему
  снимает один frame; общий `SGR 0` очищает весь stack. Это opt-in
  иерархическая интерпретация, не ответ на вопрос «что покажет терминал» для
  произвольного ANSI.
- Публичные имена и сигнатуры не меняются. H8, residual H6, hyperlink,
  unfinished seam, SDK-floor и версия вне scope.

## Что доказано пробниками до реализации

Живой пробник на `main @ ad53b97` для
`Styles.red('${fgGreen}a${fgYellow}b${resetFg}c')` дал:

```text
сейчас:  [reset][fgGreen]a[fgYellow]b[fgGreen]c[reset]
c сейчас: Style(foreground: Color16.green)
цель:    [reset][fgGreen]a[fgYellow]b[fg256Red]c[reset]
c цель:  Style(foreground: Color256.red)
```

Тем же способом подтверждены расхождения background, counter-флага inverse,
underline enum, underline extended color и font selection. Временный точный
тестовый файл из плана успешно форматируется и на текущем коде даёт ровно
шесть ожидаемых FAIL; guards вложенных `Styles` и явного `Stacked*` дают два
PASS. Временные файлы удалены, в индекс не попадали.
