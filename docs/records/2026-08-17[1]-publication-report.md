# Издание 4.0.0

независимому ревью закрылась восемью волнами. Запрет, стоявший с
2026-08-05, снят этим словом — и только для этой версии.

## Как загрузили

`dart pub publish --force`. Флаг снимает только вопрос «точно публикуем?» —
ровно тот, на который владелец уже ответил; без него команда встала бы,
потому что в этом окружении нет tty.

Токен доступа в `pub-credentials.json` был просрочен с 2026-08-15, но
refresh-token лежал рядом, и `pub` обновил доступ сам — браузерный вход не
понадобился. Ответ сервера: `Successfully uploaded ... version 4.0.0`.

Проверено не по ответу команды, а отдельным запросом:
`https://pub.dev/api/packages/ansi_escape_codes` отдаёт `latest: 4.0.0`,
время публикации `2026-08-16T19:53:29Z` (00:53 по месту), версий стало 27.
До этого latest была 3.1.2.

Тег `v4.0.0` поставлен на `1721e35` — лёгкий, как `v3.1.2` и все прежние в
этом репозитории, — и запушен.

## Что это изменило в правилах

Правило «все правки неизданные: CHANGELOG правится на месте, версия не
бампается» держалось на том, что 4.0.0 не издана. Премиссы больше нет, и
`AGENTS.md` теперь говорит другое: раздел `## 4.0.0` закрыт, новая правка
заводит новый раздел.

Отдельно стоит помнить про волну 8. Она сузила публичную сигнатуру
`transitTo`, и обоснованием было «а бесплатно это только до тега». Тег
поставлен: следующая такая правка стоит мажорной версии, потому что
удалить версию с pub.dev нельзя и пользователи уже могут на ней стоять.

Запрет остаётся на будущее: `dart pub publish`, тег версии и бамп в
`pubspec.yaml` — по прямому слову владельца, каждый раз заново.
