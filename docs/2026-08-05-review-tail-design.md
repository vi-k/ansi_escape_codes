## Раздел 1 — фиксы

### M6 — контракт равенства по видимой поверхности

Поведение не меняется. Dartdoc `State.==` фиксирует: равенство — по
видимой поверхности; история раскрутки `Stack` не сравнивается; равные
стеки могут разойтись после одинакового reset'а. У `Stack` — короткая
отсылка к контракту. Тест-пин закрепляет оба факта из ревью:
`underline.doublyUnderline == doublyUnderline` — true, и расхождение
после одинакового `resetUnderline` — документированное поведение.

### L1 — операции без изменений возвращают тот же state

`state.dart:21-25` уже обещает «нечего менять → тот же state»; `Style`
это обещание нарушает: операция строит новый объект даже без изменений,
и `NoStyle().resetItalic` вырождается в пишущий `Style`. Фикс на уровне
`Style`: операция, не меняющая ничего, возвращает `this` — `NoStyle`
чинится автоматически (он и есть Style без изменений). Точная форма
(identical-проверки в местах, где сейчас строится копия) — в плане по
фактическому style.dart. CHANGELOG Fixed.

### L2 — переход между одинаковыми поверхностями пуст

`NoStyle().transitTo(Style.terminalColors)` отдаёт `\x1B[0m` при
идентичных поверхностях — виноват шорткат с NoStyle-термом в `==`
(state.dart:230-237). Фикс — локально в `transitTo`: переход между
равными по поверхности состояниями — `''`. Сам `==` не меняется — его
поведение фиксируют M6 и существующий пин `NoStyle != terminalColors`
в `style_state_test.dart`. CHANGELOG Fixed.

### L3 — Printer с NoStyle не пишет ничего своего

`printer.dart` начинает строку безусловным reset'ом. С
`defaultStyle: NoStyle()` строка уходит как есть: ни reset'а, ни
стиля. Параметр `ansiCodesEnabled` **остаётся** — ручки ортогональны:
NoStyle значит «не навязывай свой стиль» (чужие коды в тексте проходят
насквозь), `ansiCodesEnabled: false` значит «вычисти чужие коды»
(выход — plain text). В том же коммите dartdoc Printer явно
противопоставляет пару. CHANGELOG Fixed.

### L7 — entry points: недостающие экспорты и тесты на каждую точку

`lib/style.dart` возвращает типы, которые из него нельзя именовать
(`Sgr.contains(ControlFunctionsSGR)` доступен, `ControlFunctionsSGR` —
undefined): добираем недостающие экспорты до замкнутости точки.
Экспорт-тест на **каждую** из шести точек по паттерну
`exports_test.dart` (сейчас покрыта только зонтичная): каждый
публичный тип, достижимый из точки, из неё же именуем. Судьба
дублирующего `parsing.dart` не решается — только тест замкнутости.
CHANGELOG Fixed (недостающие экспорты).

### L8 — спящий API: `IntensityStyle` прячется, `EscCommon` тестируется

`IntensityStyle` публичен, но недостижим: ни один публичный член его
не принимает и не возвращает — он живёт только в приватной истории
`Stack` (какой из пары открывался, чтобы reset снял последний). Геттер
по образцу пар семантически невозможен: bold и dim сосуществуют
(`CSI 1;2`, собственный dartdoc энума это фиксирует), единственного
значения для `bold.dim` нет. Решение пользователя: `hide IntensityStyle`
в экспортах `state.dart` из трёх точек (`ansi_escape_codes.dart`,
`parsing.dart`, `style.dart`) — тип остаётся внутренним. `EscCommon`
(флагман CHANGELOG 4.0.0, ноль ссылок в тестах) получает первый тест —
`switch` по нему. CHANGELOG Removed (тип из публичного API).
