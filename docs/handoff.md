## Что сделано в H7

### Терминальная модель по умолчанию

- `Style.call` создаёт один `Printer(defaultStyle: this)` на весь вызов.
  Split/join строк и общий printer pipeline не менялись, поэтому carry стиля,
  hyperlink, незавершённых последовательностей и residual SGR сохранён.
- Selective reset теперь очищает свойство до terminal default, который обычный
  printer проецирует на внешний `Style`. Пример
  green → yellow → `resetFg` внутри `Styles.red` возвращается к внешнему
  red, а не к предыдущему внутреннему green.
- Вложенный сценарий `Styles.red('abc${Styles.green('green')}def')` остался
  red/green/red и байт-в-байт выдаёт
  `[reset][fg256Red]abc[fg256Green]green[fg256Red]def[reset]`.

### Явная стековая модель

- `Stack`, `StackedParser`, `StackedPrinter`, `StackedSinkPrinter` и
  `runZonedStackedPrinter` не меняли реализацию. Setter по-прежнему кладёт
  frame, selective reset снимает один frame, общий `SGR 0` очищает всю
  историю до `Stack.terminalColors`.
- Dartdoc, README EN/RU и architecture теперь прямо называют `Stacked*`
  opt-in иерархической интерпретацией, которая может отличаться от состояния
  реального терминала на тех же байтах.
- Публичные имена, сигнатуры и entry points не менялись. Исправление записано
  в неизданной секции 4.0.0 CHANGELOG.

### Доказательства и ревью

- Перед правкой живой пробник подтвердил исходные и целевые байты из плана.
- Добавлено восемь тестов: один точный foreground-контракт, пять представителей
  разных reset-семейств, exact guard вложенных `Styles` и guard явных
  stacked-API.
- На исходной реализации ровно шесть проверок были красными. После фикса все
  прошли; точная обратная мутация `Printer` → `StackedPrinter` снова дала
  те же шесть падений, после восстановления снова было зелено.
- Строгое ревью проверило один printer на вызов, межстрочный carry,
  независимость exact-ожидания, неизменность stacked-кода, синхронность
  README, scope H7 и отсутствие правок public API, version, generated regions,
  H8, residual, hyperlink и unfinished seam. Материальных находок нет.

## Чего не переоткрывать

- H7 закрыт выбранной границей: обычные `Style`/`Parser`/`Printer`/
  `SinkPrinter` моделируют терминал, явно названные `Stack`/`Stacked*` —
  иерархический pop. Не пытаться сделать одну модель одновременно обеими.
- Вложенные `Styles` на обычном `Printer` остаются red/green/red; стек для
  этого сценария не нужен.
- `SGR 0` очищает rendition и residual, но не закрывает hyperlink. Канал
  ссылки остаётся рядом со `State`, не внутри него.
- Residual через `ESC 7`/`ESC 8` гарантирован внутри одного непрерывного
  разбора. Межстрочный save-slot — отдельный H8.
- `insertAfter` на unfinished seam, открытый `substring`, 8-битные C1,
  инвариант придержанных opening/link-кодов и потолок скорости `substring`
  закрыты прежними решениями.
- Публичного residual API нет; расширять его без новой спеки и решения
  владельца нельзя.
